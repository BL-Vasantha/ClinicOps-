                                

# 🏥 Project Scope

ClinicOps is a console-based clinic management application developed for **TownClinic** to replace manual paper-based operations with a structured digital system.

The application manages the complete patient visit lifecycle starting from **doctor onboarding and patient registration to appointment booking and visit completion**.

The system allows administrators to maintain doctor information, manage schedules, import doctor records, preserve clinic data, and maintain audit logs for operational traceability.

Front Desk Executives can register patients, maintain patient records, check doctor availability based on specialization, and schedule appointments using fixed **30-minute time slots**.

The application focuses on:

* Doctor registration and schedule management
* Bulk import of doctor and schedule data
* Patient registration and record management
* Doctor availability tracking by specialization
* Appointment booking with slot allocation
* Persistent storage of doctor and patient information
* Audit logging for bookings and system errors
* Reliable and maintainable clinic operations

ClinicOps aims to improve efficiency, reduce manual work, increase data accuracy, and provide better appointment coordination within TownClinic.
